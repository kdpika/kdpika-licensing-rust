# Security policy

Report suspected vulnerabilities privately to **hi@kdpika.com**. Do not put
license keys, activation tokens, customer data or private signing keys in public
issues or pull requests. Include the SDK version/commit, operating system,
reproduction steps with synthetic data and a safe request ID where available.

Do not disable TLS, Ed25519 verification or access checks as a workaround.
See the README for storage, offline operation and device-owner limitations.
The MIT license covers this Rust SDK, not the KDPika SaaS backend.

This is the initial 0.1.0 source release. No fixed response-time SLA or historical
version-support window is promised. Review changes and pin your dependency before
upgrading. Registry publication is separate; this repository does not claim a
crates.io release.
